### What's the difference between 'section' and 'div'?
Div is a generic container, it does not have any SEO benefit as it does not represent the specific type while section is a semantic tag which represents a specific theme of content that can helps the search engines to understand the page layout, also helps developers to debug or analyze the code base. 

### When would you use 'article' vs 'section'?
Section is a small part of large document we can write section inside the article. Both are resusable. Article can be broken down into section.


###  What does the defer attribute on 'script' do?
When browser tries to build the webpage, defer tells the browser to download the JS file simultaneosly and execute once html parsing is done. 


### Why should you always link 'label' to an 'input'?
Label gives the description to the particular input type and link with it for and id.

### What's the difference between 'b' and 'strong'?
Both tags make the text bold,b only represents the styling of the text but strong is semantic tag which tells to search engine, the importance of the text while reading.

### Explain srcset and sizes in your own words.
Both are used together to make image responsive with respect to the dimensions. srcset defines the list of images which is required. and sizes tell the dimensions to the browser on different layouts.
